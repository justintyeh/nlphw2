# SubmitHub

Assignment submission portal for the Tsinghua NLP course. Students can view assignments, upload files, review past submissions, and check grades — all in a clean, tabbed interface.

## Tech Stack

- **React 19** — UI components
- **Vite** — build tool and dev server
- **Tailwind CSS** — utility-first styling
- **Lucide** — icon library

## Getting Started

```bash
npm install
npm run dev
```

The dev server starts at `http://localhost:5173` by default.

## Available Scripts

| Command           | Description                        |
| ----------------- | ---------------------------------- |
| `npm run dev`     | Start the development server       |
| `npm run build`   | Build for production                |
| `npm run preview` | Preview the production build        |
| `npm run lint`    | Run ESLint                          |
